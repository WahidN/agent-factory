# Avatars

Zet hier een foto per machine neer. Bestandsnaam: `<machine-slug>.png`, waarbij
de slug de machinenaam is in kleine letters met alles buiten `a-z0-9` vervangen
door een streepje. Voorbeelden: `dennispassway-macbook.png`,
`macbook-pro-van-wahid.png`.

Eisen: vierkant, minimaal 300x300 pixels. Het bord snijdt de foto rond uit.

Ontbreekt het bestand voor een machine, dan toont het bord initialen in de
accentkleur van het lot.

Een nieuw toegevoegde foto verschijnt pas na een herlaad van de pagina; de
browsercache onthoudt ook een eerdere 404.
